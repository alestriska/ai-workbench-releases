AI Workbench

A desktop app that lets AI assistants build software for you, step by step, while you stay in charge.

What it is

AI Workbench runs on your own computer.

You describe a change in plain words. Workbench splits it into small requests.

An AI assistant builds each request. Workbench runs the tests and records what happened.

Nothing is merged until it passes review. You approve what matters.

Download

Get the newest version from the latest release.

For a Mac, download the .dmg file. For Windows, download the Setup.exe file.

Install on a Mac

You need a Mac with Apple Silicon (M1 or later) and macOS 13 or later.

  1. Double-click the downloaded .dmg file to open it.
  2. Drag AI Workbench onto Applications.
  3. Open AI Workbench from Applications.
  4. If macOS says it cannot check the app, click Done. The app is not notarized yet, so you confirm it once.
  5. Open System Settings > Privacy & Security, scroll down, and click Open Anyway next to AI Workbench.
  6. Confirm with your password or Touch ID, then click Open.

Install on Windows

You need 64-bit Windows 10 or 11.

  1. Double-click the downloaded installer (Setup.exe) to run it.
  2. If Windows says Windows protected your PC, click More info > Run anyway. The installer is not signed yet, so you confirm it.
  3. Follow the installer. It needs no administrator rights.
  4. Open AI Workbench from the Start menu.

What you need

  • Your own Claude sign-in, your own Codex sign-in, or both. Workbench uses your account; it has none of its own.
  • You do not need GitHub or GitHub CLI to install or update AI Workbench.

Update

On a Mac, use Update in the app. It needs no sign-in.

On Windows, download the newer installer from the latest release and run it.
